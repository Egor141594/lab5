# Домашнее задание к работе 5  
## Условие задачи  
Создать программу вычисления указанной величины.
Результат проверить при заданных исходных значениях. 
## Алгоритм и блок-схема  
### Алгоритм  
1.Начало
2.Объявить константу:
t = 0.5
3.Задать исходные данные:
x - значение переменной x
y - значение переменной y
4.Вычислить числитель функции:
num = pow(sin(x), 3) + log(2 * y + 3 * x);
5.Вычислить знаменатель функции:
den = pow(t, 3) + sqrt(x);
6.Вычислить итоговое значение функции:
F = num / den
7.Вывести результат расчётов:
Вывод значения F на экран с форматированием
8.Конец
